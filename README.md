## How to Use

1. **Clone the repository:**
   ```bash
   git clone https://github.com/girishlade111/site-design.git
   cd site-design
   ```

2. **Browse locally:**
   Open the folder in any file explorer or image viewer to browse the collection visually.

3. **Use as a mood board:**
   Import images into Figma, Adobe XD, or any design tool as references.

4. **Filter by category:**
   Use the file names to identify the niche — they are descriptively named.

5. **Pick your inspiration:**
   Select designs that match your project's tone and start building!

## Contributing

Contributions are welcome! If you'd like to add more design inspiration:

1. Fork the repository
2. Add your image(s) with a **descriptive file name** (e.g., `Minimal Portfolio Dark Mode.jpg`)
3. Create a Pull Request with a short description of what you added

Please ensure all images are:
- High quality (min 800px width recommended)
- Properly named (descriptive, English)
- Not duplicates of existing images
- Sourced from publicly available design showcases
